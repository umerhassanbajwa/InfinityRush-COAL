# Infinity Rush

A falling-object catching game written in x86 assembly, with a Marvel Infinity Gauntlet theme. Built for the COAL (Computer Organization and Assembly Language) course project at FAST-NUCES.

> Course project. Not affiliated with Marvel or FAST-NUCES.

## Game

Move the collector left and right to catch falling objects before the 2-minute timer runs out.

- Three kinds of score objects, worth 5, 10 and 15 points
- One kind of game-ending object that ends the run when caught
- Live score in the top-right corner and a countdown timer
- Start screen (press Enter to start) and an end screen with the final score

Controls: Left Arrow and Right Arrow to move, Enter to start.
